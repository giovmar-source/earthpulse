# EarthPulse — Product Specification V0.1

## Product

EarthPulse

## Tagline

See what satellites see. Understand what is changing.

## Core concept

EarthPulse translates Earth Observation data into simple information about environmental changes.

## V0.1 objective

Allow users to explore how vegetation changes over time in selected demonstration locations.

## Main indicator

NDVI — Normalized Difference Vegetation Index.

## Data source

Sentinel-2.

## V0.1 screens

1. Home
2. Place Detail
3. Before / After
4. How do we know?

## Place Detail

The user can see:

- latest observation
- NDVI value
- comparison with baseline
- vegetation status
- NDVI time series

## Before / After

The user can compare satellite observations from two different dates.

## Scientific transparency

The application must explain:

- satellite
- instrument
- acquisition date
- spatial resolution
- index
- calculation
- limitations

## V0.1 exclusions

The first version will not include:

- user accounts
- notifications
- payments
- advertising
- AI chatbot
- social features
- global search
- Sentinel-1
- multiple environmental indicators
- machine learning

## Future possibilities

- user-selected locations
- saved places
- alerts
- Sentinel-1
- water monitoring
- land surface temperature
- urban indicators
- fire monitoring
- AI-assisted explanations
